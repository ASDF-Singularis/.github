### 🎯 关于 Singularis

Singularis 是一套面向 **Unreal Engine 5** 的模块化插件框架。<br>
15+ 个独立插件涵盖交互、背包、建造、载具、在线服务等核心系统，<br>
为你提供开箱即用的基础设施，让你专注于创意本身。

### 🏛️ 设计哲学

每个插件严格遵循单一职责，彼此独立、非侵入式。<br>
用你所需，弃你所用——<br>
`SingularisInteraction` 不需要知道 `SingularisInventory` 的存在。<br>
高性能 C++ 底层完整暴露给蓝图，<br>
从设计之初就内建网络复制支持，<br>
单机与多人项目同步受益。

### 🔧 工程质量

框架内置自动化工具链：<br>
资产命名检查器强制执行项目规范，<br>
依赖图验证器杜绝循环引用，<br>
C++ 样板代码生成器一键产出预配置的子系统与复制组件。
