# SINGULARIS
### 引力奇点 · 模块化 UE5 框架

*CREATE WITHOUT LIMITS · 模块即自由*

### 🎯 关于

一套面向 **Unreal Engine 5** 的模块化插件框架，15+ 个独立插件涵盖交互、背包、建造、载具、在线服务等核心系统，为你提供开箱即用的基础设施，让你专注于创意本身。

### 🏛️ 设计哲学

每个插件严格遵循单一职责，彼此独立、非侵入式——用你所需，弃你所用，`SingularisInteraction` 不需要知道 `SingularisInventory` 的存在。高性能 C++ 底层完整暴露给蓝图，从设计之初就内建网络复制支持，单机与多人项目同步受益。

### 🔧 工程质量

框架内置自动化工具链，守护项目规范：

- **资产命名检查器** — 自动扫描 Content Browser，强制执行前缀规则与目录结构规范
- **依赖图验证器** — 检测并阻止蓝图模块间的循环依赖，防止打包失败与运行时崩溃
- **C++ 样板代码生成器** — 一键生成子系统、快速数组与复制组件，预配置 Singularis 日志宏
